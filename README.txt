FORECOURT WORKS LIMITED — Quotation Builder
============================================

How to run
----------
1. Unzip this package.
2. Open quotation-app/index.html in Chrome or Edge
   (double-click, or drag into the browser).
3. For best results (fonts + logo on PDF), serve the folder
   locally, e.g.:

     cd quotation-app
     python3 -m http.server 8080

   then open http://localhost:8080

Contents
--------
index.html          — App UI
app.js              — Form logic + PDF engine
fsw-pdf-theme.js    — Shared FSW document chrome
forecourt-logo-mark.png
Roboto-Regular.ttf / Roboto-Bold.ttf

Usage
-----
- Edit quotation details, items, labour, travel, terms.
- + ADD ITEM / + ADD TERMS for extra rows.
- + ADD IMAGE on each item (background cleaned automatically).
- Sign on the three pads or attach signature images.
- Click Generate PDF.

PDF matches FSW brand layout (double navy border, header,
cost summary + payment block, terms, signatures, photo page).
